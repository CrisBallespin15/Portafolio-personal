# Portafolio

Mi portafolio personal. HTML, CSS y JS, sin frameworks.

## Cómo editarlo

- Todo lo que está entre `[corchetes]` en `index.html` es para cambiar (nombre, correo, usuario de GitHub).
- Las capturas de los proyectos están en `img/`.
- Si querés poner foto, guardala en `img/foto.jpg` y descomentá la línea del `<img class="foto">`.
- Los colores están arriba de `css/style.css` en `:root`.

## Verlo

Abrí `index.html` en el navegador, o usá la extensión Live Server de VS Code.

## Subirlo a GitHub Pages

1. Creá un repo en GitHub y subí estos archivos.
2. En el repo: Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
3. En un par de minutos queda en `https://tuusuario.github.io/nombre-del-repo/`.
